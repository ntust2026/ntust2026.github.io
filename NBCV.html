01 核心極客部署流程

跟着這四個關鍵步驟，打通本地模型與 Claude Code 桌面版之間的橋樑。

步驟 1

環境準備

安裝 Git 及 Ollama 本地模型運行器。並確認主機 BIOS 已開啟 Windows 虛擬化功能。

步驟 2

部署代理工具

下載並安裝 CC Switch 與 Claude Code 桌面版。這是模型無痛偽裝的核心。

步驟 3

拉取本地模型

在終端機拉取千問（Qwen 3.5）或谷歌 Gemma 4 模型。推薦 8G 顯存跑 9B 尺寸。

步驟 4

對接與偽裝

啟用 CC Switch 本地路由與 Claude 轉發，透過設定檔讓桌面版連上 127.0.0.1 本地網關。

03 CC Switch 與系統配置生成器

專為學生定製的自動化指南：點選你的操作系統與運行模型，快速產生所需的環境配置！

⚙️ 自定義環境參數

💡 CC Switch 控制面板操作指南：
1. 點擊「新增自定義供應商」，API KEY 任意填寫（如 123456）。
2. 請求地址填入 http://127.0.0.1:11434/v1。
3. 格式切換為「OpenAI兼容」，認證選「API KEY」。
4. 將 Sonnet 模型 與 Haiku 模型 的映射值填入你的本地模型名稱。

產出的配置指令 / 註冊表補丁

WINDOWS

【第一步：終端機啟動模型】

ollama run qwen3.5:9b

【第二步：導出配置 Windows 註冊表注入修飾】

在 Claude Code 啟用開發者模式導出 .reg 註冊表後，滑鼠右鍵「記事本開啟」，在底部的 JSON 中強制注入以下映射模型選項。 

"models" = "[\"qwen3.5:9b\", \"gemma4:26b\"]"

【第二步：macOS / Linux 配置文件修改】

導出你的 Claude Code 配置文件（通常為 plist 或 json），並確保你的模型段落被更新為： 

{\n  "models": ["qwen3.5:9b", "gemma4:26b"]\n}
🎉 重要提示： 部署完成後，請徹底關閉 Claude Code 桌面客戶端（可在右下角任務欄中點選退出），接著重新啟動，選擇「本地網關 (Local Gateway)」以開始使用！

04 疑難雜症 FAQ 面板

遇到報錯不要慌！這裡整理了學生在本地配置中最容易碰到的問題與排查步驟。

這是因為運行本地模型或環境需要電腦硬體的虛擬化支持。請按照以下步驟修復：
  • 重啟電腦進入 BIOS，將 Intel Virtual Technology (VT-x) 或 AMD-V 設置為 Enabled。
  • 在 Windows 搜尋欄搜尋「啟用或關閉 Windows 功能」。
  • 勾選「Windows 虛擬機器監控平台」、「適用於 Linux 的 Windows 子系統 (WSL)」以及「虛擬機器平台」。
  • 點選確定並重啟電腦即可。
模型的選擇主要取決於你的電腦顯示卡顯存（VRAM）：
  • 千問 Qwen 3.5 (9B)：體積僅約 6.6GB，極為省資源。只要顯存在 8G 左右就可以非常流暢地運行，是絕大部分學生筆電的首選。
  • Gemma 4 (26B)：適合擁有 16G 甚至 24G 顯存的高端遊戲筆電或桌機，在代碼邏輯的理解、指令規劃等進階場景表現更佳。
請檢查以下幾項設置：
  1. 確保 CC Switch 與 Ollama 主程式都在運行，且 CC Switch 的「路由功能」總開關已開啟。
  2. 檢查你的網關地址填寫是否正確。CC Switch 的服務地址一般為 http://127.0.0.1:2333 等，而 API Key 必須與你在註冊表/配置中注入的完全一致。
  3. 確認你在 CC Switch 的自定義廠商配置中，有將 sonnet 和 haiku 對應的模型名稱修改為你本地運行的正確名稱（例如 qwen3.5:9b）。
是的！ 這正是這個玩法最吸引人的地方。

由於模型是完全下載在你的電腦硬碟上，並且利用 Ollama 本地加載運行，CC Switch 的轉發也是在本地 127.0.0.1 迴路完成，你的敏感代碼與專案檔案絕不會被上傳到外網任何伺服器。即使在拔掉網線、無網路環境下也能流暢運行 AI Agent 幫你寫代碼！
